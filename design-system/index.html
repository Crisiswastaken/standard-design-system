Design system

Design System

Quiet, monochromatic UI language. Hierarchy comes from type, spacing, and contrast — never from accent color.

v1.0 SF Pro Nucleo Micro Bold Light theme

Principles

Six rules that decide everything else

01

Monochrome only

Seven grays. No brand or accent color in UI chrome. Emphasis is a darker gray or a heavier weight.

02

Every value is a token

Color, size, space, radius — nothing hard-coded. If a value isn't in the token list, it isn't in the system.

03

40px is the control constant

Buttons, inputs, nav items and icon buttons all share one height so rows line up without thinking.

04

Borders, not shadows

Surfaces separate with a 1px #F2F2F2 line. No drop shadows by default.

05

Two weights

Regular 400 for reading, Medium 500 for emphasis, labels and buttons. Nothing heavier in product UI.

06

Pills are reserved

Full radius only for buttons, badges and toggles. Everything else uses the 4–24px scale.
