# Nucleo Micro Bold Essential

180 free Micro Bold icons (20px), cleaned as standalone SVGs.

Source: [`nucleo-micro-bold-essential`](https://www.npmjs.com/package/nucleo-micro-bold-essential)

## Usage

```html
<img src="icons/nucleo/micro-bold/check.svg" width="20" height="20" alt="" />
```

Icons use `currentColor`.
