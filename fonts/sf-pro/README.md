# SF Pro

San Francisco Pro typefaces used by the NMPL design system.

**Source:** [Apple Developer — Fonts](https://developer.apple.com/fonts/)

## Setup

Apple’s license does not allow redistributing SF Pro font files. Download them yourself and place the files in this folder:

1. Visit [developer.apple.com/fonts](https://developer.apple.com/fonts/)
2. Download **SF Pro**
3. Extract the archive into this directory (`fonts/sf-pro/`)

You should end up with files like:

```
SF-Pro.ttf
SF-Pro-Italic.ttf
SF-Pro-Text-Regular.otf
SF-Pro-Display-Regular.otf
SF-Pro-Rounded-Regular.otf
… (full Text / Display / Rounded static sets)
```

The design system preview (`design-system/index.html`) expects these filenames.
